# Love QR Site

## Sửa lời nhắn
Mở `script.js`, sửa:
- `introLine`
- `storyLines`

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub.
2. Upload 3 file: `index.html`, `style.css`, `script.js`.
3. Vào `Settings` → `Pages`.
4. Chọn `Deploy from a branch`.
5. Chọn branch `main`, thư mục `/root`, rồi `Save`.
6. Đợi khoảng 1–3 phút để GitHub cấp đường link.

Sau đó dùng đường link GitHub Pages để tạo QR.
